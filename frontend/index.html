Why Breadth-First Search?

01

Level-by-level

BFS explores all routes reachable with one boarded bus before considering journeys that need another bus.

02

Minimum buses

The first route that contains the destination gives the minimum number of boarded buses.

03

Efficient search

Shared stops connect routes, so overlapping services become interchange points.
